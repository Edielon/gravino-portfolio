Project DeRisk, Senterprisys Limited

Queensland, Australia · 2023 to present

  • 2 → 1templates merged into one system

Problem

Housing contractor Dixon Homes ran administrative and construction planning through two disconnected templates, which slowed estimating and let errors through.

Approach

Merged both templates into one system, automated task linking and removed duplicate work. Worked with estimators on cost methodology and pricing models, then built and tested interface mock-ups with the development team over several review cycles.

Result

A faster, more accurate estimating workflow now used across the team, with user manuals and checklists built in so new estimators get up to speed quickly.

Tools

MS Project · Jira · Azure DevOps · Canva
